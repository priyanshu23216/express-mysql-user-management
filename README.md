<body><h1 align="center">User Registration System</h1><p align="center">
  A web-based application for registering new users using Node.js, Express.js and MySQL.
</p><hr><h2>About The Project</h2><p>
  User Registration System is a web application that allows users to submit their details through a registration form. The application processes the submitted data using Express.js and stores user information in a MySQL database.
</p><hr><h2>Features</h2><ul>
  <li>Register new users through a web form.</li>
  <li>Handle form submissions using Express.js.</li>
  <li>Store user information in a MySQL database.</li>
  <li>Render dynamic pages using EJS.</li>
  <li>Style the interface using CSS.</li>
</ul><hr><h2>Technologies Used</h2><ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>EJS</li>
  <li>MySQL</li>
